## ✨ Why AirBeats Lite?

- 🪶 **Ultra Slim & Fast** - Stripped of heavy telemetry and unnecessary SDKs for a tiny ~8.5 MB package.
- 🎵 **Seamless YouTube Music Integration** - High-quality streaming, playlists, artist discovery, and synchronized lyrics.
- 🎨 **Pure Material Design 3** - Fluid animations, adaptive dynamic themes, and customized player layouts.
- 🏝️ **Dynamic Island Floating Pill** - Interactive music overlay controls on top of other applications.
- 🪵 **Built-in Experimental Debug Logs** - Real-time playback and network diagnostics via Timber logging.
- 🔒 **Zero Telemetry & 100% Private** - No login required, no Google API keys needed, and all preferences/history stored locally.
- 📱 **Android 7.0+ Support** - Optimized for modern and legacy Android devices.

## 🛠️ Build from Source

AirBeats Lite is completely self-contained and **requires zero API keys or external Firebase setup** to build!

### Prerequisites

| Requirement | Version |
|-------------|---------|
| **Java Development Kit (JDK)** | 21 (Temurin / OpenJDK) |
| **Android Studio** | Ladybug / Meerkat or newer |
| **Android SDK** | Compile SDK 36, Min SDK 24 |
| **Git** | Latest |

### 🚀 Build Steps

```bash
# 1. Clone the repository
git clone https://github.com/drkvenom786/airbeats-lite.git

# 2. Navigate into the project directory
cd airbeats-lite

# 3. Build Debug APK (No API keys or google-services.json required)
./gradlew assembleDebug

# 4. Find your compiled APK at:
# app/build/outputs/apk/debug/app-debug.apk
```

---

## 📦 Build Variants

```bash
# Build Release APK
./gradlew assembleRelease

# Install directly to connected device / emulator
./gradlew installDebug

# Run unit tests
./gradlew test
```
